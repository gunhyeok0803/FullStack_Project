# TCP/UDP 소켓 채팅 서버

Python 기반 소켓 서버를 C++로 재구현한 프로젝트

## 구현 내용
- TCP 에코 서버/클라이언트
- TCP 멀티스레드 서버 (다중 클라이언트 처리)
- TCP 멀티스레드 채팅 (브로드캐스트)
- UDP 에코 서버/클라이언트
- UDP 채팅 (등록/해제 프로토콜)

## 기술 스택
- C++, Winsock2, 멀티스레드(std::thread), mutex

## 핵심 구현
- 클라이언트별 스레드 분리로 다중 접속 처리
- mutex로 공유 자원(클라이언트 목록) 동기화
- TCP/UDP 프로토콜 차이 직접 구현 및 비교
